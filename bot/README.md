# 🤖 Trackcal 100% Free WhatsApp QR Bot

Personal WhatsApp Bulking Assistant with automated daily reminders and 2-way chat-to-log connected directly to your **Trackcal** cloud database (`bharath-bulking-70kg`).

---

## ⚡ 1-Minute Quick Start (100% FREE)

### Step 1: Install Bot Dependencies
Open your terminal and run:
```bash
cd bot
npm install
```

### Step 2: Start the Bot
```bash
npm start
```

### Step 3: Scan the QR Code on Your Phone
1. A QR code will display directly in your terminal.
2. Open **WhatsApp** on your phone.
3. Tap **Settings** (or 3-dots menu) ➡️ **Linked Devices** ➡️ **Link a Device**.
4. Scan the terminal QR code with your phone camera.

🎉 **That's it!** The bot is now authenticated as a linked device and will stay connected automatically.

---

## 💬 WhatsApp Chat Commands (Message Yourself or Any Chat)

| Command | Action |
| :--- | :--- |
| **`status`** / **`today`** | View today's live calories, protein left, and supplement status |
| **`creatine`** | Mark today's 3g Creatine as taken |
| **`whey`** or **`whey 2`** | Mark Whey Protein as taken (+26g protein) |
| **`weight 58.2`** | Update your body weight to 58.2 kg |
| **`log breakfast`** | Mark breakfast as logged |
| **`log lunch`** | Mark lunch as logged |
| **`log snack`** | Mark snack as logged |
| **`log dinner`** | Mark dinner as logged |
| **`workout`** | Mark today's workout completed |
| **`help`** | View list of all commands |

## ⏰ Automated Scheduled Reminders
* **9:00 PM Daily Check**: Reminds you if Creatine or Whey is still unlogged.
* **10:30 PM Night Report**: Sends you your daily calories & macro adherence score.
